## Theory
A formal language is a set of strings built from a finite alphabet, following a precise set of rules. Unlike natural languages, formal languages are designed to be unambiguous and exact, which makes them suitable for use in computer science, especially in the description of programming languages and computational systems.

These rules are defined by a grammar. The grammar specifies how symbols can be combined in order to obtain valid strings of the language. In this laboratory work, the focus is on regular grammars, which represent a restricted class of grammars with simple production rules. Despite their simplicity, regular grammars are widely used in practice, especially for describing patterns and simple syntactic structures.

To recognize the languages generated by regular grammars, finite automata are used. A finite automaton is a mathematical model composed of a finite set of states, an input alphabet, a transition function, an initial state, and a set of final states. The automaton processes an input string step by step and, after the last symbol is read, decides whether the string belongs to the language based on the state in which it stops.

A key theoretical result is that regular grammars and finite automata are equivalent, meaning they describe the same class of languages, called regular languages. This equivalence allows a language to be represented either by a grammar or by an automaton. In this project, this relationship is applied by generating strings from a grammar, converting the grammar into a finite automaton, and checking whether given strings are accepted by it.

## Implementation description

Grammar class

* The Grammar class models a regular grammar using the sets of non-terminals (VN), terminals (VT), the production rules (P), and the start symbol (S). It provides a method generateString() which repeatedly replaces non-terminals using randomly chosen productions until only terminal symbols remain. The class also contains a method toFiniteAutomaton() that converts the grammar into an equivalent finite automaton.

```
public String generateString() {
    String current = S;
    boolean done = false;

    while (!done) {
        done = true;
        for (String nt : VN) {
            if (current.contains(nt)) {
                done = false;
                List<String> productions = P.get(nt);
                String chosen = productions.get(random.nextInt(productions.size()));
                current = current.replaceFirst(nt, chosen);
                break;
            }
        }
    }
    return current;
}

```

FiniteAutomaton class

* The FiniteAutomaton class represents a finite automaton using the standard components: set of states (Q), alphabet (Sigma), transition function (delta), initial state (q0), and set of final states (F). The method stringBelongToLanguage simulates the automaton by processing the input string symbol by symbol and checking if the final state is accepting. Additionally, the static method fromGrammar builds an equivalent finite automaton from a given regular grammar.
```
public boolean stringBelongToLanguage(String input) {
    String currentState = q0;

    for (int i = 0; i < input.length(); i++) {
        String symbol = String.valueOf(input.charAt(i));
        if (!delta.containsKey(currentState)) return false;
        if (!delta.get(currentState).containsKey(symbol)) return false;

        currentState = delta.get(currentState).get(symbol);
    }

    return F.contains(currentState);
}

```

Conversion from Grammar to Finite Automaton

* The conversion method fromGrammar creates a state for each non-terminal symbol and adds an extra final state. For each production rule, a transition is added to the automaton: productions of length 1 lead to the final state, while productions of length 2 lead to the corresponding next state. In this way, the constructed automaton recognizes the same language as the original grammar.
```
if (right.length() == 1) {
    String terminal = right;
    delta.get(left).put(terminal, finalState);
} else if (right.length() == 2) {
    String terminal = String.valueOf(right.charAt(0));
    String nextState = String.valueOf(right.charAt(1));
    delta.get(left).put(terminal, nextState);
}

```
